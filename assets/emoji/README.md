# Offline emoji catalog

catalog.json contains 3,944 fully-qualified Unicode 17.0 emoji sequences. Korean labels and search terms use CLDR 48 annotations. The included source datasets permit regeneration and auditing; the app bundles the generated catalog. Noto Color Emoji supplies offline glyphs.

- https://www.unicode.org/Public/17.0.0/emoji/emoji-test.txt
- https://raw.githubusercontent.com/unicode-org/cldr/release-48/common/annotations/ko.xml
- https://github.com/googlefonts/noto-emoji/tree/main/fonts
