# Ateliai 0.8.3

앱 이름을 Ateliai로 바꾸고 사용자가 제공한 A 심벌 이미지로 Windows 실행 파일·설치 파일·바로가기 및 Android 런처 아이콘을 교체했습니다. Windows 아이콘은 16–256px 크기를 포함합니다. 기존 설치 식별자와 데이터·보안 저장소 이름은 호환성을 위해 유지합니다.

| 요청 | 처리 |
|---|---|
| 52·53 | 마지막 입력 후 2초간 추가 입력이 없을 때 자동저장. 입력 재개 시 다시 대기. 버튼은 키마다 저장 상태를 왕복하지 않음. 화면 전환·종료·수동 저장은 즉시 반영 |
| 52-1 | 같은 한글 문장을 40ms 조합 이벤트 간격으로 연속 5회, 자동저장 켜짐/꺼짐에서 총 10회 비교 |
| 52-2 | Flutter/Quill 공식 이슈의 입력 중단·포커스·IME 조합 문제를 비교. [검토 기록](INPUT-REVIEW-0.8.3.md) |
| 52-3 | 이력 기능의 입력 누락 유발은 입증되지 않아 제거하지 않음. 실제 저장 시점에만 이력을 생성하여 입력 경로에서 분리 |
| 54 | AI 버튼에 원형 곡률과 메뉴와 같은 테두리 색 적용 |
| 55 | 지침 작성 모드·시스템 프롬프트·입력 예시 제거. 일반 대화/캐릭터 프롬프트만 제공. 기존 저장 데이터는 삭제하지 않음 |
| 56 | 포커스가 없는 본문을 드래그할 때도 입력 연결 활성화. 선택 영역을 한글 조합 입력으로 치환하는 검사 추가 |
| 57 | 번호·글머리 기준선과 본문 기준선 정렬, 체크 상자와 첫 줄 중심 정렬. 큰 글자에 맞게 표식 공간 확보 |
| 58 | Ateliai 이름 및 제공 이미지 아이콘 적용 |

GitHub 업로드는 계속 보류합니다.

검증: 자동 테스트 53개 통과, 정적 검사 이상 없음.
