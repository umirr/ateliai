# 0.7.0 입력 안정화

GitHub 업로드는 사용자 요청에 따라 중지했습니다. 이 버전은 로컬 Windows 설치파일로 제공합니다.

## 수정

- 입력 때마다 새로 생성되던 편집기 포커스/스크롤 객체를 유지하여 입력 중 포커스가 검색창이나 메뉴로 이동하는 문제를 수정했습니다.
- 자동저장 중에도 입력을 유지하고 저장 시작 이후 입력은 다음 저장 대상으로 남깁니다.
- 캐릭터 잘라내기·붙여넣기: 우클릭 → 잘라내기 → 대상 폴더 우클릭 → 캐릭터 붙여넣기. 잘라내기만으로 데이터가 삭제되지 않습니다.
- 폴더의 캐릭터 수는 하위 폴더를 포함해 계산합니다. 이미지 수와 분리했습니다.
- 캐릭터 폴더만 디렉터리를 표시합니다. 스토리와 노트는 각각 자신의 항목만 표시하며, 과거 폴더 안에 있던 글도 해당 탭에서 보입니다.
- 이름 입력창의 사각형 배경/테두리를 제거했습니다.
- 서식 도구 모음은 높이 160의 고정 3줄 배치입니다. 좁은 화면에서는 가로로 스크롤합니다.
- 글자 크기: 8·12·14·18·24·32·40pt. 앱 화면의 논리 픽셀로 환산하여 적용합니다.
- 설정의 본문 행간: 1.4·1.6·1.8·2.0·2.4배, 기본 1.8배. 본문과 목록에 적용합니다.
- 선택 영역이 없을 때 서식 버튼과 서식 단축키는 글을 바꾸지 않습니다. 정렬·목록·제목은 문단 속성이므로 선택에 포함된 문단에 적용됩니다. `# + 공백`의 명시적 제목 입력은 계속 지원합니다.
- Ctrl+F는 본문 안에 검색 행을 엽니다. 검은 배경의 검색 대화상자는 사용하지 않습니다.
- Ctrl+V와 문맥 메뉴 붙여넣기를 통일했습니다. 외부 텍스트의 CRLF/LF·빈 줄을 보존하고, 앱 내부 복사본은 서식을 유지합니다. 외부 HTML 서식 대신 텍스트와 줄바꿈을 우선합니다.
- 처음 불러온 내용을 실행 취소 이력에 넣지 않으며 붙여넣기를 독립적인 실행 취소 단위로 처리합니다.
- 가운데/오른쪽 정렬된 목록 번호가 첫 글자 위치를 따라가도록 편집기 렌더러를 수정했습니다. 로컬 수정본과 MIT 라이선스는 third_party/flutter_quill에 있습니다.
- 분류 색상의 채도를 강화하고 명도를 낮췄습니다. 메뉴 전환 시 남는 카드/탭 선택 표시를 정리했습니다.
- 배경의 추출 색상 표시는 제거했으며 맞춤 테마 계산에만 사용합니다.
- 기존 '구간'은 스토리 속 한 장면을 뜻했습니다. '장면별 등장인물'로 이름을 바꾸고 장면 이름 예시를 제공합니다.

## 입력 검증

자동 테스트는 Windows 키 동작을 지정한 Flutter 테스트 환경에서 수행합니다. 실제 모든 Windows IME·키보드·클립보드 프로그램 조합을 완전히 검증했다는 의미는 아닙니다.

한글 조합 및 확정, 입력 중 재빌드, 백스페이스/Delete, 연속 삭제·빈 문서 재입력, 줄바꿈, 방향키·공백의 포커스 유지, 커서의 500ms 깜빡임, 여러 줄 선택 삭제, 이모지 삭제, CRLF/LF·빈 줄 붙여넣기, 실행 취소/다시 실행, 선택 영역 서식과 pt 크기, 본문 검색, 번호 목록 정렬을 검증합니다.
