# Storyloom 0.8.1

## 편집기와 화면

Windows 커서의 실제 그리기 높이와 선택 배경을 글자 높이에 맞췄습니다. 도구 모음의 호버 영역을 버튼 안으로 제한하고 드롭다운 폭을 고정했습니다. AI 전송 버튼의 내부 여백과 결과 복사 버튼 가운데 정렬을 조정했습니다.

캐릭터·노트에서 Ctrl 다중 선택, Shift 범위 선택, 선택 묶음의 폴더 드래그 이동과 상위 폴더 이동을 지원합니다. 모듈 사이 이동과 자기 하위 폴더로의 이동은 막습니다. 이모티콘은 Unicode 17.0의 3,944개 항목, 분류·한국어/영어 검색·피부색 선택을 제공합니다.

| 45 | 물리 Ctrl+C/X/V 처리, 클립보드 쓰기 완료 후 붙여넣기, 여러 줄 선택과 줄바꿈 보존 검증 |

## 검증 범위

자동 테스트 46개 통과. 실제 커서 페인트 높이, 연속 한글 조합과 즉시 저장, 다중 선택·이동, 긴 대화 선택·복사, 문서 참조 격리, 초기화 및 모델별 프롬프트 구성을 검사했습니다. 실제 사용자 IME의 모든 조합과 외부 AI/NovelAI의 생성 결과까지 보장하는 검증은 아닙니다. NovelAI 이미지를 직접 생성하는 기능이 아니라 해당 모델에 붙여 넣을 프롬프트를 작성하는 기능입니다.

GitHub 업로드는 보류합니다.
