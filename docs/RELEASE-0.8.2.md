## 입력 문제의 검증 범위

48번은 삭제 문제와 별개인 연속 타이핑 문제입니다. 삭제 없이 한글 조합과 영문을 이어가는 240단계 입력을 빈 문서와 기존 35,919자 문서에서 각각 검사했습니다. 자동저장 중 본문·포커스·컨트롤러가 유지되고 IME 연결 재생성/입력 상태 덮어쓰기가 없으며 재실행 후 내용이 보존되는 것을 확인했습니다. 사용자의 실제 Windows IME에서 발생한 간헐적 글자 누락 자체는 재현하지 못했으므로 완전 해결로 단정하지 않습니다.

별도로 한글 조합 중 백스페이스를 편집기가 먼저 적용하는 문제를 재현해 수정했습니다. 이것을 48번 연속 입력 문제의 원인으로 간주하지 않습니다. 조합 중 화면을 닫을 때 이미 해제 중인 위젯을 갱신하던 리스너 순서도 수정했습니다.

이모티콘 벡터 검토 근거: [Google Noto Emoji COLRv1 구성](https://github.com/googlefonts/noto-emoji/blob/main/colrv1/all.toml). 카탈로그와 문자 저장 형식은 유지합니다.

GitHub 업로드는 보류합니다.
